Slide Intermédiaire

Architecture Technique : Un Trio Complémentaire

Nginx (Le Bouclier)

Reverse proxy, terminaison TLS/HTTPS, protection frontale.

Node.js (Le Moteur)

Traitement asynchrone des WebSockets pour la télémaintenance temps réel.

MongoDB (La Mémoire)

Stockage orienté documents JSON, flexible pour logs et inventaire.

Nginx → Node.js ↔ MongoDB

Choix justifié : disponibilité élevée, flexibilité du format JSON et adaptation aux contraintes de flux en temps réel.

Diapositive 6

Phase 2 : Implémentation en Environnement "Offline"

  • Contrainte majeure : VM isolée sans accès Internet (pas de apt install / npm install direct).
  • Méthode pont : reconstruction des dépendances via transferts SFTP avec MobaXterm.
  • Sécurisation : reverse proxy Nginx pour imposer TLS.
  • Architecture : unification des flux sur le port 443 pour simplifier le firewall.
  • Design : comparaison du thème MeshCentral de base et d'une version modernisée GANIL.

Diapositive 7

MeshCentral : Une Gestion de Parc Unifiée et Web

  • Accès universel : prise en main distante via navigateur (KVM/Bureau).
  • Multi-plateforme : Windows, Linux, Mac, Android.
  • Terminal web : commandes SSH/PowerShell centralisées.
  • Transfert fichiers : upload/download sécurisé intégré.
  • Intel AMT : fonctionnalité puissante, à activer avec grande prudence.
  • Sécurité & consentement : notification utilisateur et traçabilité (RGPD).
